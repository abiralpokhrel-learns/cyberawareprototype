# CyberAware Prototype

A 360° interactive cyber-awareness training prototype for warehouse staff — built for the CET257 Enterprise Project (University of Sunderland, delivered via ISMT College Butwal).

## What it is

A single-page browser prototype that places warehouse staff inside a 360° warehouse scene. Learners explore the environment, find the cyber-risk hotspots hidden in everyday warehouse work, and get immediate feedback — training awareness without a classroom.

- Fictional training company in the scenario: **Tech Titans**
- Includes a login page before entering the scene
- Built as one self-contained `index.html` — no build step, no dependencies

## Run it

Open `index.html` in a browser, or use the live GitHub Pages deployment linked from this repo.

## Context

Created as the working prototype deliverable for the CET257 Enterprise Project (solo build). It demonstrates the concept for client review — a proof of concept, not a production training platform.
